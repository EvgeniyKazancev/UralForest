# ООО ТПК «Уральский лес» — сайт продажи пиломатериалов

Готовый сайт для продажи пиломатериалов в Екатеринбурге на **Python + Django**.
Сделан по мотивам `pilo-ru.ru` (дизайн), с каталогом и корзиной как на `derevo-urala.ru` и `ekb-les.ru`.

Сайт полностью готов к работе: **осталось наполнить каталог в админке и раскатать на сервер**.
Оплата (ЮKassa: карта + СБП) встроена, кнопки работают в демо-режиме — для реальных платежей нужно
только вставить ключи в `.env`.

## 2. Быстрый запуск на localhost (Windows)

Откройте терминал в папке проекта `uralforest` и выполните:

```powershell
# 1. (необязательно) виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Зависимости
python -m pip install -r requirements.txt

# 3. База данных
python manage.py migrate

# 4. Первичная настройка: админ, категории, контакты, стартовый контент
#    (флаг --with-demo добавит несколько демонстрационных товаров)
python manage.py init_site --with-demo

# 5. Запуск
python manage.py runserver
```

Откройте в браузере: **http://127.0.0.1:8000/**

> Если `python` не найден, используйте `py` вместо `python`.

### Готовый скрипт

Можно просто запустить `start.bat` — он выполнит шаги 2–5 автоматически.

## 4. Подключение реальной оплаты (ЮKassa)

1. Зарегистрируйтесь как продавец на **https://yookassa.ru** и получите **Shop ID** и **секретный ключ**
   (раздел «Настройки → API»).
2. Скопируйте `.env.example` в `.env` (файл `.env` уже создан для локалхоста) и укажите:

   ```env
   PAYMENTS_ENABLED=True
   YOOKASSA_SHOP_ID=123456
   YOOKASSA_SECRET_KEY=live_xxxxxxxxxxxxxxxxxxxx
   ```

3. В личном кабинете ЮKassa укажите URL уведомлений (webhook):
   `https://ваш-домен.рф/payments/webhook/`
4. Перезапустите сайт. Кнопки «Оплатить картой» и «Оплатить по QR-коду (СБП)» начнут открывать
   реальную платёжную форму, а статусы заказов будут обновляться автоматически.

Пока ключей нет — работает демо-экран (`/payments/mock/...`), который проходит тот же сценарий
без списания денег. Это позволяет проверить весь путь «корзина → заказ → оплата».

## 6. Публикация на сервере (кратко)

1. Скопируйте проект на сервер, установите зависимости:
   `pip install -r requirements.txt`
2. В `.env` задайте:
   - `DJANGO_DEBUG=False`
   - `DJANGO_SECRET_KEY=` (длинный случайный ключ)
   - `DJANGO_ALLOWED_HOSTS=ваш-домен.рф,www.ваш-домен.рф`
   - `DJANGO_CSRF_TRUSTED_ORIGINS=https://ваш-домен.рф`
   - ключи ЮKassa и `PAYMENTS_ENABLED=True`
3. Примените миграции и соберите статику:
   ```bash
   python manage.py migrate
   python manage.py collectstatic --noinput
   ```
4. Запустите через Gunicorn/uWSGI (Linux) и настройте Nginx. Пример для Gunicorn:
   ```bash
   gunicorn uralforest.wsgi:application --bind 0.0.0.0:8000
   ```
   Whitenoise уже настроен и раздаёт статику сам. Медиафайлы (`media/`) отдайте через Nginx.
5. Для PostgreSQL раскомментируйте блок `DB_*` в `.env` (и установите `psycopg[binary]`).

## 7. Автоматическое развёртывание на Ubuntu

Скопируйте проект на сервер и выполните одну команду (нужен домен, указывающий на сервер):

```bash
cd /srv/uralforest
sudo DOMAIN=ваш-домен.рф bash deploy/deploy.sh
```

Скрипт `deploy/deploy.sh` сам: установит пакеты, создаст venv, поставит зависимости,
сгенерирует `.env` со случайным секретным ключом, применит миграции, соберёт статику,
создаст админа, настроит Gunicorn (systemd) и Nginx, при желании выпустит SSL-сертификат.

Полезные переменные: `APP_USER`, `PORT`, `ADMIN_EMAIL`, `ADMIN_USER`, `ADMIN_PASS`, `INSTALL_SSL=yes|no`.

Управление службой:
```bash
sudo systemctl status  uralforest
sudo systemctl restart uralforest
sudo journalctl -u uralforest -f
```

Шаблоны конфигов лежат в `deploy/`: `gunicorn.service`, `nginx.conf`.

## 8. Развёртывание через Docker / Portainer

В проекте есть `Dockerfile`, `docker-compose.yml` и `docker/entrypoint.sh`.
Контейнер сам при старте применяет миграции, собирает статику, при первом запуске
создаёт администратора и категории, затем поднимает Gunicorn на порту `8000`.

### Вариант A. Через Portainer из Git-репозитория (рекомендуется)

1. Загрузите проект в Git-репозиторий (GitHub/GitLab) — из вашей локальной машины:
   ```bash
   cd D:\PythonProject1\uralforest
   git init && git add . && git commit -m "site"
   git remote add origin https://github.com/ваш-логин/uralforest.git
   git push -u origin main
   ```
2. В Portainer: **Stacks → Add stack → Repository**.
   - Repository URL: ссылка на ваш репозиторий
   - Compose path: `docker-compose.yml`
3. В разделе **Environment variables** задайте значения (или отредактируйте `docker-compose.yml`):
   `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS`, `DJANGO_CSRF_TRUSTED_ORIGINS`,
   `ADMIN_PASSWORD`, при необходимости ключи ЮKassa.
4. **Deploy the stack**. Portainer соберёт образ из `Dockerfile` и запустит контейнер.
5. Сайт будет доступен на `http://IP-сервера:8000/`.

### Вариант B. Готовый образ из реестра

Соберите образ у себя (Docker Desktop) и запушьте в Docker Hub / приватный реестр:

```bash
docker build -t ваш-логин/uralforest:latest .
docker push ваш-логин/uralforest:latest
```

В Portainer Stack замените `build: .` на `image: ваш-логин/uralforest:latest`,
либо добавьте образ через **Images → Pull image**.

### Важные моменты

- **Порт**: в `docker-compose.yml` указано `"8000:8000"`. Если порт занят — поменяйте левое число,
  например `"8080:8000"`.
- **Домен/HTTPS**: удобнее поставить перед контейнером reverse-proxy (Nginx Proxy Manager,
  Traefik) и направить его на `http://IP:8000`, а сертификат выдать там.
- **Данные** сохраняются в томах `uralforest_data` (база) и `uralforest_media` (фото, логотип) —
  при пересоздании контейнера они не теряются.
- **Пароль администратора** задаётся переменной `ADMIN_PASSWORD` и применяется при самом первом
  запуске. Если не задать — сгенерируется случайный и будет выведен в логах контейнера (Logs).
- **Оплата ЮKassa**: укажите `PAYMENTS_ENABLED=True`, `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`
  и webhook `https://домен/payments/webhook/`, затем пересоздайте контейнер.

### Локальная проверка (если есть Docker Desktop)

```bash
cd D:\PythonProject1\uralforest
docker compose up --build
```
Откройте http://localhost:8000/
